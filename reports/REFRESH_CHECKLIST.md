# Refresh checklist — what must be regenerated before the report is final

Two engine fixes are in flight. Everything derived from the **current**
`fisher` differential test or from `proportion` is **provisional** and must be
regenerated against the corrected data. This file is the complete list plus the
exact commands.

**The distinction that decides what survives:**

| kind of finding | status | why |
|---|---|---|
| Findings **about** `fisher`/`proportion` misbehaving | **FINAL** | They characterise the engine being replaced and are the evidence that motivated replacing it. A corrected test does not make the old one well-behaved retroactively. |
| Findings **using** `fisher`/`proportion` as a measuring instrument | **PROVISIONAL** | The measurement is wrong, so the biology read off it is unknown. |

Concretely: "fisher calls 43% of PAS significant" stays. "ABL1 switches in 15
cell types" does not.

### Commands

```bash
# 1. harvest, on the server (read-only against the corrected run)
python reports/_server_scripts/s7_switch_deepdive.py \
    --run <RUN>/B1_cohort_full \
    --out <OUT>/deepdive \
    --diff-strategy mwu_percell \
    --secondary-strategy nb_multi \
    --hallmark reports/cumulative_analysis/refs/msigdb_hallmark.gmt \
    --skip-shannon                       # shannon is unchanged; saves ~10 min

# 2. the cross-experiment fisher-derived tables (figs 35, 36)
python -m ema.benchmark.cross_experiment \
    --sweep-root <SWEEP> --out <OUT>/cross_experiment --atlas <ATLAS>

# 3. figures
python reports/generate_switch_deepdive_figures.py \
    --in reports/cumulative_analysis/deepdive \
    --out reports/figures/corrected \
    --depth reports/cumulative_analysis/cross_experiment/switch_depth_by_stage.tsv
python reports/generate_cross_experiment_figures.py \
    --in reports/cumulative_analysis/cross_experiment \
    --out reports/figures/corrected
```

`s7` stamps the strategy name into its column headers
(`n_tests_<strategy>`), and `generate_switch_deepdive_figures.py` recovers it
via `strategy_names()`, so the figures relabel themselves. Verified against the
current tables.

**Assumed output layout** for the replacement test — if it differs, `s7` needs a
small change, not a rewrite:

```
<celltype>/<strategy>/differential/<strategy>_<contrast>.tsv
columns: pas_id, gene_id, qvalue, delta_proportion,
         n_cells_cluster1, n_cells_cluster2, log2fc
```
